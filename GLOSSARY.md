# Glossary

**Host**:
A computer running `goslid`, storing project files and running development tools, including AI tools.  
_Synonyms_: Server

**Client**:
An application for interacting with a host.

**Project root**:
A configured directory under which `goslid` discovers projects.

**Project**:
A directory used as the working directory for terminal sessions.

**Terminal session**:
An interactive session on the host through which a client sends terminal input and receives terminal output.  
_Synonyms_: Terminal

**AI tool**:
A program or service available to the server for processing AI requests, through a terminal session or directly.  
_Synonyms_: AI agent

**Relay**:
A component that forwards communication between clients and servers.
