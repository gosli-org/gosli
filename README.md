# Gosli

Remote project terminals from anywhere.
Self-hosted access to your existing development environment.
Open a project, start a terminal, and run your coding agents — from any device.

## Your environment stays. You move.

Your server remains the single source of truth. Projects, files, and tools stay where they are.
Gosli provides access to your existing environment without moving or syncing it.

## Zero client setup

No SSH keys, VPN configuration, or terminal emulators required.
